# Support

Use [GitHub Discussions](https://github.com/WolfpackOfOne/Q-agent/discussions)
for setup questions, design questions, and student help. Search existing
discussions and documentation before starting a new one.

Use a structured [GitHub issue](https://github.com/WolfpackOfOne/Q-agent/issues/new/choose)
for reproducible bugs, feature proposals, and documentation corrections.

Use [private vulnerability reporting](https://github.com/WolfpackOfOne/Q-agent/security/advisories/new)
for security issues or credential exposure. Never paste secrets, private data,
QuantConnect identifiers, or proprietary datasets into a public post.
